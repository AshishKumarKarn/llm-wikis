## Key themes
1. **People management:** no surprises in performance reviews; continuous feedback > annual reviews.
2. **Cross-team conflicts:** start EM-to-EM; escalate with options, not complaints.
3. **Tech debt:** categorize (risk/velocity/cosmetic); 15–20% sprint capacity.
4. **Architecture decisions:** data + benchmarks + PoC; "disagree and commit."
5. **Production outages:** stabilize → communicate → blameless postmortem → systemic fix.
6. **Agile:** Scrum for fast-change products; Kanban for continuous delivery / support.
