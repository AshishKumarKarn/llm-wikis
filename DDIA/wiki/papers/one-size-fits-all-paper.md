# "One Size Fits All": An Idea Whose Time Has Come and Gone

Michael Stonebraker & Uğur Çetintemel, 21st ICDE, April 2005.

The reference DDIA Ch 1 cites for the claim that data tools no longer fit neatly into
traditional categories — the single general-purpose database giving way to a
diversity of specialized engines (the premise behind treating databases, caches,
queues, search indexes, batch and stream processors all as composable "data
systems").
