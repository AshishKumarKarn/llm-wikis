# The Log: What Every Software Engineer Should Know About Real-Time Data's Unifying Abstraction

Jay Kreps, engineering.linkedin.com, December 16, 2013.

The influential argument that an **append-only log** is the unifying abstraction for
data integration — connecting databases, [[change-data-capture|CDC]], derived
systems, and stream processing. Underpins DDIA Ch 11's treatment of
[[log-based-message-brokers]] and [[state-streams-immutability]] (and the
[[apache-kafka|Kafka]] design philosophy). *(DDIA Ch 11)*
